# Tanıtım videosu yazı tipleri

Bilgisayar tanıtım videosunda (masaustu_video.py) afiş/gönderi tarzı yazı için.
Hepsi Google Fonts'tan, SIL Open Font License 1.1 ile (assets/fonts/OFL.txt):

- Anton-Regular.ttf: büyük, sıkışık başlıklar
- BebasNeue-Regular.ttf: bölüm etiketi (aralıklı büyük harf)
- DMSerifDisplay-Italic.ttf: başlıktaki vurgulu kelime
- Caveat-Variable.ttf: ekrandaki el yazısı ok etiketleri
